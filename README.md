# MIDNIGHT · 天黑，请闭眼

一个使用原生 HTML、CSS 和 JavaScript 制作的网页狼人杀小游戏，支持单机 AI 对局和基于 P2P 的真人联机。

## 功能

- 6–12 人游戏与自定义阵营人数
- 狼人、预言家、女巫、猎人和村民角色
- 夜晚行动、白天讨论、投票放逐和胜负结算
- 单机 AI 玩家
- 房间号真人联机
- 昼夜视觉系统、身份卡和事件动效
- 桌面端与移动端响应式布局
- 原创狼影村庄插画、五种角色画像与隐藏身份的空椅子
- 全黑主界面、无边框全幅角色卡、白天时钟发言轨道与卡牌入箱投票动画
- GSAP 驱动的轨道转身、投票托盘和卡牌入箱动画；资源不可用时自动回退到 CSS
- 默认关闭、在浏览器本地合成的可选音效
- 结算后的三幕故事回顾与 SVG 故事卡下载（仅采样已公开事件）

## 本地运行

项目不需要安装依赖。在项目目录运行：

```bash
python3 -m http.server 8090 --bind 127.0.0.1
```

然后打开：

```text
http://127.0.0.1:8090/
```

## 项目结构

- `index.html`：页面结构
- `style.css`：界面与响应式样式
- `game.js`：游戏规则和单机逻辑
- `net.js`：真人联机连接
- `compose.js`：界面组合与状态呈现
- `fx.js`：昼夜氛围和事件特效
- `midnight.css`：MIDNIGHT 绘本视觉与响应式覆盖层
- `midnight.js`：入场、章节标题、可选声音及终局故事卡；不读取房主隐藏状态
- `motion.js`：GSAP 动画层，不参与游戏状态和身份判断
- `assets/`：本项目原创插画与生成说明

## 设计与维护

角色画像只依据现有私有视图中的头像更新。未知角色始终显示同一个空椅子，
死亡、本人身份和狼队友的可见性沿用现有规则。请不要从房主的完整玩家数据推断画像。
动效观察器不能无条件修改自己正在监听的属性；这曾导致夜晚界面卡死。
减少动态效果模式禁用首页视差和身份卡位移动画，声音不会自动开启。
