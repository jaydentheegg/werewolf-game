# MIDNIGHT · 天黑，请闭眼

一个网页狼人杀：前端是原生 HTML、CSS 和 JavaScript，配一个很小的 Node 服务。
AI 玩家接入 Claude，会自己记笔记、推理、伪装、发言和投票；也支持基于 P2P 的真人联机。

## 功能

- 6–12 人游戏与自定义阵营人数
- 狼人、预言家、女巫、猎人和村民角色
- 夜晚行动、白天讨论、投票放逐和胜负结算
- **会思考的 AI 玩家**：每个 AI 带着自己的性格、私人笔记和只属于它的信息（查验结果、刀口、用药），
  白天读完所有人的发言和票型再开口，夜里狼人之间会互相提议刀谁；终局可以回看每个 AI 一路上的内心独白
- 没有服务或没配 Key 时自动退回经典规则 AI，游戏照常可玩
- 房间号真人联机
- 昼夜视觉系统、身份卡和事件动效
- 桌面端与移动端响应式布局
- 原创狼影村庄插画、五种角色画像与隐藏身份的空椅子
- 全黑主界面、无边框全幅角色卡、白天时钟发言轨道与卡牌入箱投票动画
- GSAP 驱动的轨道转身、投票托盘和卡牌入箱动画；资源不可用时自动回退到 CSS
- 电影式全屏开始菜单，支持鼠标、键盘方向键和回车操作
- 默认关闭、在浏览器本地合成的可选音效
- 结算后的三幕故事回顾与 SVG 故事卡下载（仅采样已公开事件）

## 本地运行

需要 Node.js 20.12 或更高版本。

```bash
npm install
npm start
```

然后打开 <http://localhost:8787/>，在开局清单的 **BRAIN** 一行里粘贴你的 Claude API Key，点「连接」即可。
服务端会先用它查一次模型信息验证（不花 token），能用才换上。勾选「记住」会把它写进本机的 `.env`，下次启动自动接入；
不勾就只在这次运行里有效。之后可以在同一处「更换 Key」或「移除 Key」。

- Key 只发给这台电脑上的游戏服务：不会存进浏览器，服务端也从不把它回传给页面（页面上只显示 `sk-ant-…1234` 这样的尾巴），
  更不会发给联机的其他玩家。
- 只有坐在运行服务那台电脑前的人能填 / 改 Key；`HOST=0.0.0.0` 时局域网里的人能玩，但改不了 Key。
- 也可以照旧写配置文件：`cp .env.example .env` 后填 `ANTHROPIC_API_KEY`，或直接设同名环境变量
  （环境变量里的 Key 页面上删不掉，只能在终端里改）。

BRAIN 一行还能切回经典规则，或打开「旁观心声」（单机时把 AI 的内心独白实时写进纪事，会剧透）。

没有 API Key 也能玩：

- `npm run mock`：用离线模拟大脑跑通整条流程（不调 API，适合调样式 / 调试）
- 直接双击 `index.html`，或用任意静态服务器打开：AI 座位使用经典规则

### AI 配置（`.env` 或环境变量）

| 变量 | 默认 | 说明 |
|---|---|---|
| `ANTHROPIC_API_KEY` | — | Claude API Key（也可以在页面上填） |
| `AI_MODEL` | `claude-opus-5` | 模型 |
| `AI_EFFORT` | `low` | 思考力度 `low` / `medium` / `high`，越高越会想，也越慢越贵 |
| `AI_TIMEOUT` | `45` | 单次决策超时（秒），超时的座位这一次退回经典规则 |
| `AI_MOCK` | — | 设为 `1` 等同 `npm run mock` |
| `PORT` / `HOST` | `8787` / `127.0.0.1` | 默认只给本机用；改成 `0.0.0.0` 会让局域网里的人也能花你的额度 |

一局 8 人大约要调用几十次模型（每次发言、投票和夜间行动各一次）。
Claude 被安全策略拒答时会自动换模型重试（server-side fallback），仍失败的那一次退回经典规则。

联机时只有房主需要跑服务：AI 座位都在房主页面上思考，其他人照常用房间号加入。

### 测试

```bash
npm test
```

不需要 API Key：Claude 一侧用本地假服务顶替，检查发出去的请求和返回值的校验。

## 项目结构

- `server/index.js`：本地服务——托管页面，并提供 `/api/ai/*`（保管 / 验证页面填的 API Key、替 AI 座位调用 Claude）
- `server/brain.js`：AI 的「大脑」——把某个座位能看到的局面写成提示词，用结构化输出拿回决定并校验
- `server/mock.js`：离线模拟大脑（`npm run mock`）
- `ai.js`：浏览器端的 AI 接入层，探测服务、发送决策请求、渲染 BRAIN 设置；连不上就让 AI 座位退回经典规则
- `index.html`：页面结构
- `style.css`：界面与响应式样式
- `game.js`：游戏规则、单机逻辑，以及 AI 座位的记忆（公开记录 / 私密信息 / 笔记）与决策校验
- `net.js`：真人联机连接
- `compose.js`：界面组合与状态呈现
- `fx.js`：昼夜氛围和事件特效
- `midnight.css`：MIDNIGHT 绘本视觉与响应式覆盖层
- `midnight.js`：入场、章节标题、可选声音及终局故事卡；不读取房主隐藏状态
- `motion.js`：GSAP 动画层，不参与游戏状态和身份判断
- `assets/`：本项目原创插画与生成说明

## 设计与维护

角色画像只依据现有私有视图中的头像更新。未知角色始终显示同一个空椅子，
死亡、本人身份和狼队友的可见性沿用现有规则。请不要从房主的完整玩家数据推断画像。
动效观察器不能无条件修改自己正在监听的属性；这曾导致夜晚界面卡死。
减少动态效果模式禁用首页视差和身份卡位移动画，声音不会自动开启。
