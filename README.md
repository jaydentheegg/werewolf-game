# 天黑，请闭眼 · 网页狼人杀

一个使用原生 HTML、CSS 和 JavaScript 制作的网页狼人杀小游戏，支持单机 AI 对局和基于 P2P 的真人联机。

## 功能

- 6–12 人游戏与自定义阵营人数
- 狼人、预言家、女巫、猎人和村民角色
- 夜晚行动、白天讨论、投票放逐和胜负结算
- 单机 AI 玩家
- 房间号真人联机
- 昼夜视觉系统、身份卡和事件动效
- 桌面端与移动端响应式布局

## 本地运行

项目不需要安装依赖。在项目目录运行：

```bash
python3 -m http.server 8090 --bind 127.0.0.1
```

然后打开：

```text
http://127.0.0.1:8090/
```

## 项目结构

- `index.html`：页面结构
- `style.css`：界面与响应式样式
- `game.js`：游戏规则和单机逻辑
- `net.js`：真人联机连接
- `compose.js`：界面组合与状态呈现
- `fx.js`：昼夜氛围和事件特效
